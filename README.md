# Advanced Probabilistic Machine Learning

## Project Overview

This repository contains the implementation and report for a project in Advanced Probabilistic Machine Learning.

The project explores probabilistic modelling and inference methods, with a focus on Variational Inference (VI) and their application to diffusion MRI data.

## Repository Contents

- `dmri_project.py` – Main Python implementation.
- `dmri_projectVIonly.py` – Implementation focusing on Variational Inference.
- `Report.pdf` – Project report.
- `dmri_project 3.py.zip` – Archived project files.

## Methods

The project investigates probabilistic machine learning approaches for modelling and analysing data.

## Requirements

- Python 3
- Required Python packages used in the implementation.

## How to Run

Clone the repository:

```bash
git clone https://github.com/SimonaSimonaSimona/Project-in-Advanced-Probabilistic-Machine-Learning.git
```

Navigate to the project directory:

```bash
cd Project-in-Advanced-Probabilistic-Machine-Learning
```

Run the main script:

```bash
python3 dmri_project.py
```
